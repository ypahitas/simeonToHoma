# το χώμαν / To Homan

Static bilingual (Greek/English) website for the album **το χώμαν** ("To Homan"), traditional songs of Cyprus by Symeon Mercouris with Stelios Papamichael. Live at https://tohoman.eu.

Plain HTML/CSS/JS, no build step. Preview with `python -m http.server 8000` from the repo root and open http://localhost:8000.

Everything a developer or AI agent needs to continue the work (sources, fixed decisions, code structure, fonts, open items) is in [CLAUDE.md](CLAUDE.md).
